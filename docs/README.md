# Toss Product Challenge Documentation

이 폴더는 토스 과제 프로젝트의 의사결정, 리서치, 레퍼런스 분석, 제출 답변 초안을 보관하는 공간이다.

## 폴더 구조

- `decisions/`: 중요한 제품/UX/디자인/구현 의사결정 기록
- `references/`: Mobbin, 기존 캘린더, 경쟁 서비스, 리서치 레퍼런스 분석
- `plans/`: 작업 계획과 진행 전략
- `submission/`: 제출용 답변 초안과 최종 문안

## 운영 규칙

- 중요한 논의가 생기면 `docs/decisions/YYYY-MM-DD-topic.md`로 남긴다.
- 대화 중 생긴 분석 문서는 가장 가까운 폴더에 저장한다.
- 새 문서가 생기면 `docs/INDEX.md`를 함께 갱신한다.
- 나중에 "정리" 요청이 오면 이 폴더를 기준으로 중복/흩어진 문서를 다시 묶는다.

# 1번 답변 초안: 문제 정의

## 질문

사용자의 어떤 문제를 발견했나요? 그것이 왜 문제라고 생각했나요? 기존 캘린더 서비스들의 UX에서 발견한 문제, 혹은 주제 안에서 새롭게 정의한 문제에 대해 알려주세요.

## 제한

- 최대 700자
- 공백 포함
- 목적은 리서치 전체 요약이 아니라, 우리가 발견한 핵심 문제를 선명하게 말하는 것

## 현재 핵심 문제

회의 일정 조율의 핵심 문제는 `빈 시간 찾기`가 아니라, 서로 다른 제약을 가진 참석자들 사이에서 주최자가 납득 가능한 시간을 정하기 어렵다는 점이다.

기존 캘린더는 가능한 시간대를 찾는 데는 도움을 주지만, 다음 정보를 같은 기준으로 정리해주지 않는다.

- 필수 참석자가 가능한가
- 선택 참석자는 빠져도 되는가
- 누군가에게 비선호나 확인 필요가 있는가
- 그 사유를 어디까지 공개해야 하는가
- 왜 이 시간이 최종 선택인지 설명할 수 있는가

## 제출용 초안

기존 캘린더는 회의 일정을 잡을 때 비어 있는 시간을 찾는 데는 도움을 주지만, 그 시간이 왜 좋은 선택인지 판단하게 해주지는 못한다고 봤습니다. 주간/월간 뷰는 빈칸은 잘 보여주지만, 후보 간 차이를 비교할 맥락은 흩어져 있어 선택의 책임이 주최자에게 남습니다. 특히 6명의 동료처럼 참석자가 늘어나면 조건은 단순한 가능/불가능이 아니라 필수 참석 여부, 비선호 시간, 외근·이동 가능성, 확인이 필요한 개인 사정처럼 서로 다른 강도로 섞입니다. 이때 좋은 시간의 기준은 모두 가능한 시간이 아니라, 회의 성립 조건을 충족하면서 부담을 최소화하는 시간입니다. 주최자는 후보 시간을 보면서도 누구의 조건을 얼마나 고려해야 할지 혼자 해석해야 하고, 결국 다시 메시지로 확인하거나 누군가에게 양해를 구해야 합니다. 반대로 참석자는 병원, 육아, 집중 업무처럼 공개하기 조심스러운 이유가 있어도 왜 안 되는지를 설명해야 한다는 눈치를 느낍니다. 그래서 저는 이 과제의 핵심 문제를 빈칸 탐색이 아니라, 서로 다른 제약을 같은 기준으로 정리해 주최자가 납득 가능한 결정을 내리고 참석자는 부담 없이 조건을 전달하게 하는 문제로 정의했습니다. 문제는 일정 입력이 아니라, 확정 전 판단을 돕는 정보 구조라고 보았습니다.

## 답변 구조

1. 기존 캘린더의 한계: 빈 시간은 찾지만 좋은 선택의 기준은 주지 못함
2. 상황의 복잡성: 필수 참석, 비선호, 외근, 확인 필요가 서로 다른 강도로 섞임
3. 사용자 문제: 주최자는 혼자 해석하고 반복 확인하며, 참석자는 사유 설명 부담을 느낌
4. 새 문제 정의: 서로 다른 제약을 같은 기준으로 정리해 납득 가능한 결정을 돕는 문제

## 답변에서 줄일 것

- 회의 목적별 추천 기준을 길게 설명하지 않는다.
- 프라이버시를 별도 문제처럼 앞세우지 않는다.
- 선택 참석자 불참 손실을 과하게 강조하지 않는다.
- AI 추천, 점수화, 자동 확정 이야기는 1번에서 꺼내지 않는다.

## 이후 답변과의 연결

- 2번 답변에서는 이 문제를 `후보 시간 판단 카드`와 `참석자 조건 요약 신호`로 해결했다고 설명한다.
- 3번 답변에서는 개인 사유를 직접 공개하지 않고, 점수 대신 근거와 다음 액션을 보여준 이유를 설명한다.
